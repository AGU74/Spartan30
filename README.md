# Fitness Industry Media（仮称）

日本と世界のフィットネス・ウェルネス業界を、業界人向けに短時間でキャッチアップできるメディア。
Instagram / Threads / Newsletter を中心に「情報収集 → 編集 → 要約 → 配信」で運営する。

> **Media is the acquisition channel. Network is the asset. Services are the business.**

2026年8月27日着手、2026年12月31日を第一区切りとする。

## 前提（2026-08-27 時点）

- 事業形態: B2B業界メディア（Instagram / Threads / Newsletter / Web）
- Instagram: 未開設〜500人
- 稼働: 週10〜25時間
- 初期投資: 〜30万円
- 残り期間: 18週間（2026-12-31 まで）
