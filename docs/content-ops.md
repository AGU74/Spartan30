# 制作オペレーション

情報を「探す」時間をゼロに近づけ、「編集する」時間に集中させるための設計。

---

## 1. チャネル設計 — それぞれの役割を混同しない

| チャネル | 役割 | 主な層 | 頻度 | KPI |
|---|---|---|---|---|
| **Reels** | リーチエンジン（発見） | 周辺層 | 週4〜5本 | リーチ、非フォロワー率 |
| **Carousel** | 信頼・保存エンジン | コア層 | 週3〜4本 | 保存率、プロフィール遷移 |
| **Threads** | 速報・業界人の溜まり場 | **コア層（比率が最も高くなる）** | 毎日3〜5 | 返信数、業界人からの反応 |
| **Stories** | 導線・関係維持 | 両方 | 毎日3枚 | Newsletter遷移、リンククリック |
| **Newsletter** | **事業の資産** | コア層 | 週1（月曜7時） | 購読者数、開封率、**属性** |
| **Web** | アーカイブ・SEO・登録導線 | 検索流入 | 随時 | 登録転換率 |

### なぜ Carousel だけでは伸びないか

Instagram の配信は Reels 優位が続いている。Carousel は既存フォロワーと保存に強いが、
**新規リーチを取る力が弱い**。構想の「基本はCarousel」のままだと、
コア層には刺さるが人数が増えず、1.5万人には到底届かない。

→ **Reels で発見させ、Carousel で信用させ、Newsletter で囲う。** この3段構えにする。

### Threads を軽視しない

業界人（経営者、マーケター、ブランド担当）は Threads にいる。
Instagram より会話が生まれやすく、**業界人と直接つながる確率が最も高いチャネル**。
速報を投げるだけでなく、他の業界人の投稿に返信して回ること自体がネットワーク構築になる。

## 2. 情報ソース — 探すのをやめる

毎朝20分の巡回で全部拾える状態を作る。RSS または Google アラート → Notion の Inbox に集約。

### 海外

| ソース | 種別 | 使い方 |
|---|---|---|
| Fitt Insider | ニュースレター・記事 | 業界動向の一次巡回先。**翻訳転載はしない**。事実だけ取り、自分の視点で書く |
| Athletech News | ニュース | 新店舗・提携・ローンチ |
| Welltodo | ニュースレター | ウェルネス・ブランド動向（英・欧州） |
| Club Industry | 業界誌 | ジム運営・オペレーション |
| HFA（旧IHRSA） | 業界団体 | 統計・レポート・カンファレンス |
| Crunchbase / PitchBook | データベース | 資金調達・M&A。アラート設定 |
| 各ブランド公式（WHOOP, Oura, On, HOKA, Gymshark 等） | プレスリリース | **プレスキットの画像利用条件を必ず確認** |

### 国内

| ソース | 種別 | 使い方 |
|---|---|---|
| PR TIMES（スポーツ・ヘルスケアカテゴリ） | プレスリリース | RSS購読。国内ニュースの最速ソース |
| Fitness Business / クラブビジネスジャパン | 業界誌 | 定期購読推奨。国内業界の一次情報 |
| 上場企業のIR | 決算資料 | RIZAPグループ、セントラルスポーツ、ルネサンス、東急スポーツオアシス 等。**決算資料は数字の宝庫でDATAコンテンツの原料になる** |
| 帝国データバンク／矢野経済研究所 | 調査レポート | 市場規模。プレスリリース部分は無料で使える |
| 経産省 特定サービス産業動態統計 | 官庁統計 | 月次の業界売上動向 |
| スポーツ庁 | 官庁 | 政策・補助金・スポーツ実施率調査 |

### 運用

```
毎朝 20分：
  Notion Inbox を開く → 使えるものに「NEWS / BUSINESS / BRAND / TREND / DATA」タグ
  → 週次の企画候補プールへ

毎週日曜 30分：
  プールから今週の企画を確定（Carousel 4 / Reels 5 / Newsletter TOP10）
```

**「今日は何を投稿しよう」と考える時間をゼロにする。** これが継続できるかどうかの分岐点。

## 3. フォーマット

### Carousel（構想のフォーマットを踏襲、1枚追加）

| 枚目 | 内容 |
|---|---|
| 1 | **強いHeadline。**「PILATES IS BOOMING IN JAPAN」— 英語＋日本語の併記で目を引く |
| 2 | What happened?（事実。誰が・何を・いつ） |
| 3 | 数字 / Background |
| 4 | **Why it matters**（← ここがFitt Insiderとの共通点であり、最大の差別化） |
| 5 | What's next? |
| 6 | **出典＋Newsletter導線**（← 追加。信用と回収の両方） |

**Why it matters が書けないニュースは投稿しない。** 単なる転載になり、業界人には価値がない。

### Reels

15〜30秒。周辺層向けだが、内容は業界的であること。

- 海外の新しいジム・スタジオの映像＋「これが今アメリカで増えている」
- 新プロダクト（ウェアラブル、器具）の紹介＋数字
- 「日本にまだ来ていない◯◯」シリーズ
- データを視覚化した10秒（市場規模、成長率）

**冒頭2秒：**結論先出し／数値提示／「日本にはまだない」／否定・逆張り。
挨拶・自己紹介は入れない。

### Threads

発見した瞬間に、20〜60字で投げる。編集しない。

> ◯◯が新フォーマットを発表。日本上陸は未定。

これで十分。速報性が価値であり、完成度は価値ではない。

### Newsletter — Weekly Fitness Brief

毎週月曜 朝7時。

```
■ 今週のTOP10（各60〜100字＋出典リンク）
■ Deep Dive（1本だけ、600〜1,000字の解説）
■ JOBS（今週の求人3〜5件）
■ 数字（1つだけ。市場データや決算から）
```

**購読者が10人でも配信する。16週連続の継続実績が、最終的に最大の営業資料になる。**

## 4. 週次スケジュール（約20時間）

| 曜日 | 作業 | 時間 |
|---|---|---|
| 毎朝 | ソース巡回20分＋Threads投稿 | 0.5h×7 |
| 日 | 週次企画確定、Newsletter執筆 | 3.5h |
| 月 | **Newsletter配信（7時）**、Carousel 2本制作 | 3h |
| 火 | Reels 3本撮影・編集 | 2h |
| 水 | Carousel 2本制作 | 2.5h |
| 木 | Reels 2本、業界人へのDM・返信 | 2.5h |
| 金 | インタビュー取材 or 営業 | 2.5h |
| 土 | 予備・Stories撮り溜め | 1.5h |
| | **合計** | **約21h** |

### 削減策（時間が足りなくなったら、この順で）

1. Carousel を週4本→3本に（Reelsは減らさない。リーチが止まる）
2. デザインを外注（11月から、月¥30,000）
3. Reels の撮影をまとめ撮りに
4. **Newsletter は絶対に減らさない**

## 5. 著作権・引用のポリシー

キュレーションメディアで最も事故が起きやすい領域。先に決めておく。

| 対象 | ルール |
|---|---|
| **事実** | 誰が・何を・いつ・いくら、という事実そのものに著作権はない。**自由に扱える** |
| **文章表現** | 他媒体の文章をなぞる／翻訳して載せるのは著作権侵害。**必ず自分の言葉で書き直す** |
| **画像** | 各社のプレスキット（利用条件を確認）、自前撮影、または公式アカウントの正規リポスト。**Web検索で拾った画像は使わない** |
| **ロゴ** | 事実の報道目的での使用は一般に許容されるが、スポンサー・提携を示唆する使い方はしない |
| **出典** | 全投稿・全記事に出典を明記。Carouselは最終ページ、Newsletterは各項目にリンク |
| **引用** | 短い引用は可。「引用部分が明確」「主従関係がある（自分の記述が主）」「出典明示」の3条件を満たすこと |
| **PR表記** | スポンサー案件は必ず「PR」「Sponsored」を明示。編集記事とデザインを分ける |

**業界メディアの信用は一度の誤報・一度の無断使用で失われる。** 迷ったら使わない。

## 6. コンテンツ配分

構想の7カテゴリ（NEWS / BUSINESS / BRAND / TREND / DATA / PEOPLE / JOBS）を、二層構造に割り当てる。

| カテゴリ | 主な対象層 | 主なチャネル | 週の目安 |
|---|---|---|---|
| NEWS | 両方 | Threads / Carousel | 毎日（Threads） |
| BUSINESS | **コア** | Carousel / Newsletter | 週2 |
| BRAND | 周辺 | Reels / Carousel | 週2 |
| TREND | 周辺 | **Reels** | 週2〜3 |
| DATA | **コア** | Carousel | 週1 |
| PEOPLE | **コア** | Carousel / Newsletter | 月2〜4（10月開始） |
| JOBS | **コア** | Stories / Newsletter | 週1（11月開始） |

**9月の配分：**コア向け40% / 周辺向け60%（まずリーチを作る）
**11月以降：**Newsletterの業界人比率を見ながら調整。30%を切ったらコア向けを増やす

### PEOPLE が最も強力な理由

インタビューを依頼された経営者・ブランド担当は、**ほぼ必ず自分のアカウントで拡散する**。
その人のフォロワーは業界人である確率が高い。つまり **PEOPLE はコア層獲得のための最も効率の良い施策**であり、
同時にネットワーク構築そのものになる。10月から月2〜4本を必ず回す。
