## 00. 構想の評価 — どこが正しく、どこを直すか

### 正しい部分（そのまま進める）

## 01. 市場の大きさ — 1.5万人は何を意味するか

### 日本のフィットネス業界の実数

| 指標 | 数値 | 出典・時点 |
|---|---|---|
| フィットネス市場規模 | 約7,100億円 | 2024年度、過去最高更新見込み（帝国データバンク） |
| 全国フィットネス施設数 | 13,876施設 | 2025年8月（うち24時間型 5,034、ヨガ型 1,877） |
| フィットネスクラブ就業者数 | 60,174人 | **2002年**の経産省統計。当時の事業所数は1,708 |

就業者数の公式統計は古い。ただし事業所数が 1,708 → 13,876（約8倍）に増えていることから、
**現在の就業者は概ね15〜25万人規模**と推定できる。うちパート・アルバイトが6割強を占めるため、
**正社員・マネジメント層は5〜8万人程度**。

ここに周辺領域（ウェアラブル、サプリ、アパレル、スポーツ用品、施設開発、代理店、投資家、行政）を加えると、

> **コアTAM（この事業のターゲット全体）= 概ね 5万〜10万人**

### そして、ここが最も重要な計算

このうち **Instagram で業界情報を能動的に追う人**は、多く見て10〜25%。

> **リーチ可能な業界人 = 5,000 〜 25,000人**

つまり **「業界人だけでフォロワー1.5万人」は、TAMのほぼ上限を取り切ることを意味する。**
4ヶ月どころか、数年かけて到達する数字だ。

参考モデルと比べると、さらにはっきりする。

| | Instagram | 期間 | TAM |
|---|---|---|---|
| Fitt Insider | 148,000 | 約7年 | 英語圏グローバル（米国だけで業界就業者100万人超） |
| Wellworthy | 54,000 | 数年 | 英語圏グローバル・Consumer寄り |
| **この事業（目標）** | **15,000** | **4ヶ月** | **日本語・業界人5〜10万人** |

**Fitt Insider が7年かけた到達点の1/10を、1/20のTAMで、1/20の期間で取る**——という目標になっている。

### 結論：1.5万人を、二層構造として定義し直す

1.5万人を諦める必要はない。ただし**「業界人1.5万人」は不可能**なので、こう定義する。

| 層 | 人数イメージ | 何を見に来るか | 事業価値 |
|---|---|---|---|
| **コア層**（業界人） | 1,500 〜 3,000 | BUSINESS / DATA / JOBS / PEOPLE | **事業価値のほぼ全部** |
| **周辺層**（感度の高い一般） | 12,000 〜 13,500 | TREND / BRAND / NEWS | リーチと社会的証明を担う |

周辺層は無意味ではない。**スポンサーに「1.5万人」と言える数字**であり、
Reels のリーチを稼ぎ、そのリーチの中にコア層が混ざって流れ込んでくる。
Wellworthy 型のコンテンツが周辺層を集め、Fitt Insider 型のコンテンツがコア層を沈殿させる——これが二層構造の設計だ。

**ただし、この事業の成否を決めるのはコア層とNewsletterであって、1.5万という数字ではない。**
構想の §15 に書かれている通りだ。KPIをそこに置く。

## 02. ポジションと媒体名

### ポジショニング（構想のまま）

> 日本と世界のフィットネスビジネスを、1分でキャッチアップ。

一般消費者向けではなく、**フィットネス・スポーツ・ウェルネス業界に関わる人のためのメディア**。

### 媒体名（9月第1週で決定する）

命名の制約：

- **Fitt / Insider / Wellworthy を想起させる名前は避ける。** 商標上のリスクに加え、「日本版◯◯」と見られると格が下がる
- 日本語話者が一度で読めて、検索で一意に当たること
- Instagram / Threads / ドメイン（.com または .jp）のハンドルが同時に空いていること
- **将来 Recruiting / Events / Consulting に展開しても違和感がない**こと（メディア名がサービス名の親になる）

命名の方向性：

| 方向 | 性格 | 注意点 |
|---|---|---|
| カテゴリ宣言型 | 領域そのものを名乗り、一番乗りの地位を取る | 一般名詞すぎると商標登録できず、SEOでも埋もれる |
| 造語型 | 商標を取りやすく、検索で一意になる | 意味が伝わるまで説明コストがかかる |
| 編集部型 | 個人ではなく編集部として名乗る | 属人性が下がり、利益相反を回避しやすい（§04と関係） |

決定手順：候補3つ → J-PlatPat（無料）で第35類・第41類・第16類を検索 → ハンドルとドメインの空き確認 → その週のうちに全プラットフォームを押さえる。

## 03. Newsletter を Day 1 から始める — 構想からの最大の変更点

構想 §6 では Newsletter を「長期的には非常に重要」と位置づけ、§13 の Stage 2（IG 5,000人）以降に置いている。
**これは順序が逆で、この事業では最も損の大きい判断になる。**

### 理由1：業界人はInstagramではなくメールで読む

経営者・マネージャー・マーケターは、業務時間中にInstagramを開かない。メールは開く。
コア層に本当に届くチャネルはNewsletterであって、Instagramではない。

### 理由2：スポンサーに売れるのはNewsletterであって、フォロワー数ではない

B2Bメディアのスポンサー営業で提示できるのは、フォロワー数ではなく以下だ。

- 購読者数
- **開封率**（B2Bニュースレターで40〜50%あれば強い）
- **購読者の属性**（所属企業・役職）
- クリック率

**購読者500人・開封率45%・購読者の6割が業界人**——このデータがあれば、フォロワー3,000人でもスポンサーは取れる。
逆に、フォロワー1.5万人でも属性が示せなければ、B2Bスポンサーは値付けできない。

構想 §13 は「IG 10,000人 → スポンサー販売開始」としているが、この順序だと**2027年まで1円も入らない**。

### 理由3：Audience Quality を測れる唯一の場所

構想 §12 の「Audience Quality」は正しいが、Instagramのインサイトでは職業属性は分からない。
**Newsletter登録フォームに「所属」「役職」を必須項目で入れる。これがこの事業の計測装置になる。**

登録フォーム項目（これ以上は増やさない。増やすと登録率が落ちる）：

```
メールアドレス（必須）
お名前（必須）
所属（必須・自由記述）
職種（必須・選択式）
  □ ジム/スタジオ 経営・運営     □ トレーナー/インストラクター
  □ ブランド/メーカー           □ マーケティング/PR/代理店
  □ 投資家/金融                 □ 施設開発/不動産
  □ 業界志望・学生               □ その他（フィットネス好き）
```

この選択式の集計結果が、そのままスポンサー営業の媒体資料になる。

### Weekly Fitness Brief

- 毎週月曜 朝7時配信
- 内容：先週の業界ニュース TOP10 ＋ 1本の短い解説（Why it matters）
- **9月第1週から配信開始。購読者が10人でも配信する。**
- 16週連続で欠かさないこと自体が、最大の実績になる

ツール：Substack（無料・国際的に標準）または beehiiv。日本語配信も問題ない。独自ドメインは後から接続できる。

## 04. 利益相反 — この構想では、前提条件になる

消費者向けの発信より、**業界メディアのほうが利益相反は遥かに深刻**になる。理由は3つある。

1. **競合ブランドを扱う。** F45、Orangetheory、Barry's、ピラティス各社、他のフィットネスレース——所属先の競合のニュースを、中立的に、時に好意的に扱うことになる
2. **スポンサーを取る。** 所属先の競合から広告費を受け取る可能性がある
3. **求人を扱う。** 競合企業の採用を助けることになる

さらに、メディアとしての**中立性**そのものが問われる。所属先のニュースを扱えば身内びいきに見え、扱わなければ不自然になる。

### 3つの選択肢

| 選択肢 | 内容 | 評価 |
|---|---|---|
| **A. 開示して公認を得る** | 所属先に事前に相談し、運営を認めてもらう。プロフィールに所属を明記 | **推奨。** 業界内部にいることが最大の強みになる。ただし編集の自由度は制約される |
| B. 編集部名義で個人を出さない | 媒体名のみで運営し、個人名を出さない | 中立性は保てるが、匿名メディアは業界内で信用されにくく、取材・人脈が作れない |
| C. 独立後に本格化 | 2026年は準備に留める | 最も安全だが、「2026年中に形にする」という目標を放棄することになる |

### いずれを選んでも、Phase 0 で明文化すること

- 副業規定・競業避止義務の確認（契約書。不明なら書面で確認を取る）
- **編集ポリシー**：所属先および関連団体のニュースをどう扱うか。「自社関連は扱わない」か「扱うが関係性を毎回明記する」か。後者を推奨
- **業務で得た情報・素材は一切使わない。** 未公開情報、参加者リスト、業務中に撮影した素材
- スポンサー受け入れ基準：所属先の直接競合から受けるかどうかを、事前に決めておく

**この整理を先送りしたまま伸ばすと、伸びた瞬間に本業と事業の両方を失う。**

構想には制作コストの見積もりがない。ここが計画の生死を分ける。

| 制作物 | 1本あたり | 週の本数 | 週合計 |
|---|---|---|---|
| Carousel（ニュース解説5枚） | 80分（調査30/執筆20/デザイン30） | 3〜4本 | 4.5h |
| Reels（トレンド・ブランド紹介） | 40分 | 4〜5本 | 3.0h |
| Threads（速報） | 5分 | 20〜25本 | 1.8h |
| Stories | — | 毎日3枚 | 1.2h |
| Newsletter（週1） | 180分 | 1本 | 3.0h |
| ソース巡回・選別 | — | 毎朝20分 | 2.3h |
| コメント・DM返信 | — | 毎日20分 | 2.3h |
| 営業・企画・その他 | — | — | 2.0h |
| **合計** | | | **約20時間** |

**週10〜25時間の上限に近い。** つまり、これ以上は増やせない。増やすなら以下で吸収する。

1. **Carouselを完全テンプレート化する。** Canvaでマスターを1つ作り、差し替えるのは文字と数字だけ。デザインを毎回考えない
2. **情報ソースを自動で集める。** 手で探すのをやめる（[content-ops.md](content-ops.md) にソース一覧）
3. **11月からデザインを外注。** 月3万円。テンプレートがあれば外注しやすい
4. **Threadsは移動時間で書く。** 机に座る作業にしない

## 06. 収益 — 2026年内に、いくら入るのが現実的か

構想 §14 の月商110万円（スポンサー4社×10万＋Sponsored 4本×10万＋求人10件×3万）は、
**到達すべき正しいゴール**だが、時期は **2027年後半〜2028年**が現実線だ。

### なぜ2026年内には届かないか

- **最初の1社を取るのが最も難しい。** 実績ゼロの媒体に年間スポンサーを出す企業はまずない。単発のSponsored Postから始めて実績を作るしかない
- **求人3万円×10件は、初期には売れない。** 採用企業はROIが読めない媒体に出稿しない。**JOBSは最初は無料掲載にする**——求人が集まる → 求職者が集まる → 採用が決まる → 有料化できる、という順序が必要
- 媒体資料（メディアキット）を作れるだけのデータが、11月まで揃わない

### 2026年内の現実的な売上

| 月 | 動き | 売上 |
|---|---|---|
| 9月 | 媒体立ち上げ。売らない | ¥0 |
| 10月 | 売らない。データを貯める | ¥0 |
| 11月 | 媒体資料完成、10社に提案開始 | ¥0 |
| 12月 | Sponsored Post 1〜2本 × ¥80,000〜150,000 | ¥80,000〜300,000 |
| **累計** | | **¥8万〜30万** |

**2026年は売上を作る年ではない。Audienceと実績を作る年だ。**
ここに無理な売上目標を置くと、オーディエンスの質を犠牲にする判断（安易なPR、関係ない案件）をしてしまう。それがこの事業で最も避けるべきことだ。

### 単価の考え方（12月以降の提案用）

| メニュー | 価格 | 内容 |
|---|---|---|
| Sponsored Post | ¥80,000〜150,000 | Instagram Carousel + Threads + Newsletter 掲載のセット |
| Newsletter Presenting Sponsor | ¥100,000/月 | 「Weekly Fitness Brief presented by ◯◯」＋ヘッダー枠 |
| Featured Job | ¥30,000 | 2027年以降。それまで無料 |
| Brand Feature（記事＋Web掲載） | ¥200,000 | 2027年以降 |

**値引きより、無料の実績づくりを優先する。** 最初の2〜3社は無料でも構わない。事例と数字を持つことのほうが価値が高い。

|---|---|
| **利益相反** | Phase 0 で整理（§04）。最大かつ最優先のリスク |
| **著作権・引用** | 事実（誰が・何を・いつ・いくら）に著作権はないが、表現をなぞると侵害になる。海外記事の翻訳転載はしない。画像は各社のプレスキットか自前。出典を毎回明記（[content-ops.md](content-ops.md) にポリシー） |
| **継続できない** | 週20時間はギリギリ。テンプレート化と外注化を前倒しする。**Newsletterだけは何があっても止めない** |
| **業界人が集まらない** | 10月末でNewsletterの業界人比率が30%を切っていたら、コンテンツがConsumer側に寄りすぎている。BUSINESS/DATA の比率を上げる |
| **中立性の毀損** | スポンサー記事は必ず「PR」と明示。編集記事とスポンサー記事のデザインを明確に分ける |
| **情報の誤り** | 業界メディアの信用は一度の誤報で失われる。一次情報（IR、プレスリリース、本人）に当たる。伝聞は「〜と報じられている」と出典付きで書く |
