# Spartan30 事業計画（2026年9月〜12月）

作成日: 2026-08-27 / 対象期間: 2026-09-01 〜 2026-12-31（18週間）

---

## 0. 最初に — この計画の前提と、正直な達成確率

「2026年中に形にする」と言ったとき、**残りは18週間**しかない。これを踏まえた設計にしてある。

**フォロワー1.5万人について。** ゼロから4ヶ月で15,000人は、規律よく実行しても達成確率は高くない。
リール中心・週10本投稿を18週間続けた場合の現実的な着地は、経験則で以下のように分布する。

| シナリオ | 12/31時点フォロワー | 起きること |
|---|---|---|
| 下振れ（P20） | 2,000〜4,000 | 型が見つからないまま本数だけ増える |
| 中央値（P50） | **6,000〜9,000** | 勝ち型を1〜2個見つけ、安定して伸びる |
| 上振れ（P25） | **15,000+** | 10万リーチ級の「当たり」が月2〜3本出る |

つまり **1.5万人は「当たり本数」に依存する上振れ目標**であって、努力量だけで到達できる数字ではない。
だからこの計画では2つのことをやる。

1. **当たりが出る確率を最大化する**（＝打席数を増やす。本数・型の検証速度がすべて）
2. **8,000人でも事業が成立する設計にする**（＝フォロワー数に売上を依存させない）

2の方が重要だ。**フォロワー1.5万人は事業ではない。** 日本のフィットネス領域でフォロワー1.5万人のPR単価はせいぜい1件2〜5万円で、それだけで食えるものではない。
稼ぐのは「自社商品 × LINE リスト」であり、Instagram はその入口にすぎない。この順序を間違えると、フォロワーは増えたのに1円も入らない状態になる。

## 1. 事業コンセプト

### 一行で

**日本語で存在しない「ハイブリッドフィットネス（走る×筋力）の実践知」をInstagramで無料配布し、30日プログラムとコミュニティで回収するメディア事業。**

### なぜこの領域か

- HYROX をはじめとするハイブリッドレースは日本で急拡大しているが、**日本語の実践コンテンツがほぼ存在しない**。英語圏には大量にある。この非対称が参入機会。
- 競技人口の増加＝検索・視聴需要の増加が構造的に確定している（レース開催数が先行指標）。
- 「筋トレ系」「ランニング系」は飽和しているが、**その中間は空いている**。飽和市場でのポジション取りではなく、空白地帯の一番乗りを狙う。
- 発信者自身が業界内部にいるため、一次情報・現場・人脈にアクセスできる（※ただし後述の利益相反の線引きが必須）。

### ターゲット（優先順）

| 順位 | 誰 | 状態 | 刺さる訴求 |
|---|---|---|---|
| 1 | ハイブリッドレース初挑戦層（30〜45歳） | エントリー済みだが何を練習すべきか分からない | 「本番までの30日で何をやるか」 |
| 2 | 筋トレ経験者で有酸素が苦手な層 | ジム歴3年以上、走ると死ぬ | 「重いものは挙げられるのに1km走れない理由」 |
| 3 | ランナーで筋力が課題の層 | フルマラソン完走済み | 「後半に脚が終わるのは心肺ではなく筋力」 |

**捨てるターゲット:** ダイエット目的の初心者。市場は大きいが競合が最も多く、単価も低く、差別化できない。

### 提供価値の核

「がんばれ」ではなく**数値と再現手順**。すべてのコンテンツに秒数・重量・回数・心拍が出る。
これが感覚論しかない日本のフィットネス発信との差になる。

## 2. ブランド名について — 先に潰すべきリスク

**"Spartan30" という名前は、この事業では使わないほうがいい。**

- Spartan Race Inc. は "SPARTAN" 系の商標を運動競技・イベント役務（第41類）等で各国に登録しており、**日本でも登録がある**。フィットネス／レース領域は指定役務が直撃する。
- 「フィットネス関連の商品を売るメディア」という用途は、まさに競合すると判断されやすい区分。
- 半年〜1年育てたブランドを警告書1通で捨てるリスクは、この事業規模では取るに合わない。

### 対応（9月第1週で完了させる）

1. **J-PlatPat（無料）で「スパルタ」「SPARTAN」を第41類・第25類・第9類で検索**し、登録の有無を自分の目で確認する。
2. 候補名を3つ用意し、同様に検索。Instagram・ドメイン（.com/.jp）・YouTube のハンドル空き状況も同時確認。
3. 決めたら**その週のうちに全プラットフォームのハンドルを押さえる**（無料）。商標出願は売上が立ってから（1区分 出願¥12,000 + 登録¥32,900、自力出願可）。

### 命名の方向性（例、これ自体を採用する必要はない）

| 方向 | 例 | 狙い |
|---|---|---|
| 数値・基準型 | `SUB60`, `30DAYS HYBRID` | 目標が名前に入る。検索されやすい |
| カテゴリ定義型 | `HYBRID BASE`, `ハイブリッド道場` | 領域そのものを名乗る。一番乗りの利 |
| 人格型 | 本名／既存の呼称 | 商標衝突がほぼゼロ。属人化が代償 |

**判断基準:** ①商標が空いている ②日本語話者が一度で読める ③商品名に展開できる ④自分が3年間名乗って恥ずかしくない。

> リポジトリ名 `Spartan30` は、**30日プログラム＝プロダクトの内部コードネーム**として残す分には問題ない。対外的なブランド名として出さなければよい。

## 3. 利益相反の線引き（HYROX Japan 業務との関係）

これは事業リスクではなく**キャリアリスク**なので、9月第1週に片付ける。

| 確認事項 | やること |
|---|---|
| 副業規定・競業避止義務 | 雇用契約／業務委託契約を読み直す。不明なら書面で確認を取る |
| 公式アカウントとの競合 | 自分のアカウントが公式の代替にならない設計にする（公式＝大会情報、自分＝個人の実践知） |
| 素材・情報の使用 | 業務で撮影した素材、未公開の大会情報、参加者リストは**一切使わない**。私物のカメラで、自分の時間に撮ったものだけ |
| 発言の立場 | プロフィールに「個人の見解」を明記。公式見解と読まれる書き方をしない |
| スポンサー案件 | 公式のスポンサーと競合する企業の案件を受ける前に、必ず所属先に相談 |

**この線引きを曖昧にしたまま伸ばすと、伸びた瞬間に問題になる。** 逆に、線引きが明確なら業界内部にいることは純粋な強みになる。

## 4. 収益モデル

### 構造

```
Instagram（無料・リーチ獲得）
    ↓ 転換率 8〜12%
LINE公式アカウント（リスト・関係構築）  ← ここが本当の資産
    ↓ 転換率 3〜8%
30日プログラム ¥9,800（フロント商品）
    ↓ 転換率 20〜30%
月額コミュニティ ¥2,980/月（ストック収益）
```

**アルゴリズムは自分の資産ではない。LINEリストだけが自分の資産。**
アカウントが凍結されても、リーチが落ちても、リストがあれば事業は続く。だからすべての導線をここに集める。

### 商品

| 商品 | 価格 | 内容 | 投入時期 |
|---|---|---|---|
| 30日プログラム | ¥9,800 | 週4回×4週のメニューPDF＋動画、フォーム解説、進捗シート | 11月 |
| 月額コミュニティ | ¥2,980/月 | 月次メニュー更新、質問回答、記録共有、月1オンライン会 | 12月 |
| 個別コーチング | ¥30,000/月 | 定員5名。単価が高く、商品開発の一次情報源になる | 12月（テスト） |
| PR案件 | ¥30,000〜/件 | 補助的。**主軸にしない**（依存すると発信が濁る） | 12月以降 |

### 売上計画（保守側の想定：12/31フォロワー8,000で計算）

| 月 | フォロワー | LINE登録 | 主な動き | 売上 |
|---|---|---|---|---|
| 9月 | 800 | 60 | 仕込み。売らない | ¥0 |
| 10月 | 3,000 | 250 | プレセールス（先行20名 ¥6,800） | ¥136,000 |
| 11月 | 5,500 | 500 | 正式ローンチ 25本 | ¥245,000 |
| 12月 | 8,000 | 800 | 第2期35本＋コミュニティ50人 | ¥492,000 |
| **累計** | | | | **¥873,000** |

フォロワーが15,000に届いた場合、12月売上は¥90万前後まで伸びる。ただし**計画は8,000で立てる**。上振れは結果であって前提にしてはいけない。

### 「形になった」の定義（12/31時点の合格ライン）

これを満たしたら成功と見なす。フォロワー数は含めない。

- [ ] 開業届提出済み、屋号付き口座開設済み
- [ ] 商品が1つ以上、実際に**お金を払った顧客**に届いている（10人以上）
- [ ] LINEリスト 500人以上
- [ ] 単月売上 ¥30万以上
- [ ] 「勝ち型」のコンテンツフォーマットが再現可能な形で言語化されている
- [ ] 顧客の成果事例（ビフォーアフターの数値）が3件以上ある

## 5. 18週間ロードマップ

### Phase 0 : 8/27〜8/31（今週・5日間）— 意思決定

判断を全部ここで終わらせる。走り出してから悩むと2週間溶ける。

- [ ] ブランド名の決定（J-PlatPat 検索 → 候補3つ → 決定）
- [ ] Instagram / YouTube / TikTok のハンドル取得
- [ ] 副業規定・競業避止義務の確認
- [ ] ターゲットの最終確定（上記1〜3の優先順）
- [ ] 撮影場所の確保（自宅／ジム／屋外の3パターン。ジムは撮影許可を必ず取る）
- [ ] 最初の30本の企画リスト作成（ここでまとめて出す。毎日考えるのは続かない）

### Phase 1 : 9/1〜9/30 — 立ち上げと型の探索

**目的はフォロワーではなく「何が伸びるかのデータ」。** 9月は売らない。

- 投稿: リール **週10本**（平日2本）＋ストーリーズ毎日3枚
- プロフィール完成（1行で誰の何を解決するか／ハイライト3種／リンク1本）
- 40本投稿し終えた時点で、上位20%（8本）の共通点を言語化する
- LINE公式アカウント開設、無料特典（PDF「ハイブリッドレース攻略チェックリスト」）を用意
- 開業届・屋号付き口座
- **月末判定: 800フォロワー / 保存率2%超の投稿が5本以上**

### Phase 2 : 10/1〜10/31 — 量産と最適化

- 投稿本数を維持したまま、**勝ち型の変奏を全体の70%**に。残り30%で新しい型を試す
- LINE導線を全投稿に設置（プロフィールリンク＋ストーリーズ＋固定投稿）
- 同規模アカウントとのコラボ3本（お互いのリールに出る。最も費用対効果が高い成長施策）
- 30日プログラムの中身を作る（自分自身がテスターとして30日回す）
- 月末に**先行20名のプレセールス ¥6,800**（値引きの代わりに感想と数値データをもらう）
- **月末判定: 3,000フォロワー / LINE 250人 / 売上¥13万**

### Phase 3 : 11/1〜11/30 — 収益化

- プレセールス組の30日が完走 → **成果事例を3件作る**（これが以後の全販促物になる）
- 正式ローンチ ¥9,800。LINEで5日間の教育シーケンス → 販売
- 編集を外注に切り出す（月3万円）。自分の時間を企画と撮影に集中
- **月末判定: 5,500フォロワー / LINE 500人 / 売上¥24.5万**

### Phase 4 : 12/1〜12/31 — 拡大と締め

- 第2期販売＋月額コミュニティ開始
- 年末年始需要（「新年から変わる」層）に合わせた企画を12/20〜1/5に集中投下。**ここが年内最大の山**
- PR案件の受け入れ体制（媒体資料1枚、単価表）
- 2026年の総括と2027年計画
- **月末判定: 上記「形になった」チェックリスト**

## 7. リスクと打ち手

| リスク | 影響 | 打ち手 |
|---|---|---|
| **商標衝突** | ブランド作り直し。数ヶ月の損失 | Phase 0 で確定させる。曖昧なまま進めない |
| **利益相反** | 本業に影響。最悪、両方失う | Phase 0 で書面確認。素材・情報の分離を徹底 |
| **アルゴリズム変動／凍結** | リーチが一夜で消える | LINEリストへの逃がしを最優先。全投稿に導線 |
| **1.5万人に届かない** | モチベーション崩壊 | 売上目標は8,000人で設計済み。**フォロワーはKPIであって目標ではない**と最初から扱う |
| **属人化・燃え尽き** | 週10本が続かない | まとめ撮り（月2回で1ヶ月分）＋11月から編集外注。**自分がやるのは企画と出演だけ**にする |
| **薬機法・景表法** | 措置命令、アカウント停止 | 「痩せる」「治る」「効く」を使わない。効果は**自分の実測値の報告**として書く。他人の成果は「個人の感想」明記 |
| **怪我** | 発信も練習も止まる | 高強度の撮影を週2回まで。撮影のために無理をしない |

## 8. この計画で最も重要な3行

1. **打席数がすべて。** 週10本を18週間続けられるかどうかで結果の9割が決まる。質は本数の副産物として上がる。
2. **フォロワーではなくLINEリストを追え。** 1.5万人のフォロワーより500人のリストのほうが金になる。
3. **9月は売らない。** 型が見つかる前に売ると、売れない理由が商品なのか集客なのか永遠に分からなくなる。
