# KPI トラッカー

毎週月曜、10分で埋める。埋めながら考えない。**埋めてから考える。**

---

## 見る数字は6つだけ

| KPI | 取得場所 | 合格ライン | 意味 |
|---|---|---|---|
| 投稿本数 | 自分で記録 | **10本/週** | 唯一、意志で完全にコントロールできる数字 |
| 総リーチ | インサイト | 月次目標を12週で按分 | 分母 |
| 非フォロワー率 | インサイト | **70%以上** | 低い＝新規に届いていない＝伸びない |
| 保存率（保存÷リーチ） | インサイト | **2%以上** | 「価値がある」の最も正直な指標。いいね数より重要 |
| フォロー転換率（新規フォロー÷非フォロワーリーチ） | 計算 | **1.2%以上** | プロフィールとCTAの成績 |
| LINE 登録数 | LINE管理画面 | フォロワーの**8%以上** | **事業の実体。ここだけは絶対に落とさない** |

フォロワー数そのものは記録するが、**判断には使わない**。上記6つの結果でしかないため。

## 数字が悪いときの読み方

| 症状 | 原因 | 打ち手 |
|---|---|---|
| リーチが低い（<1,000） | 冒頭2秒が弱い／型が刺さっていない | 冒頭を作り直す。5つの型の配分を変える |
| リーチはあるがフォローされない | プロフィールと投稿がつながっていない | プロフィール1行目を書き直す。投稿の一貫性を上げる |
| 保存率が低い | 消費されて終わる内容 | 教育型（型B）の比率を上げる |
| 非フォロワー率が低い | 既存フォロワーに配られているだけ | 新しい型を試す。ニッチすぎる内容を広げる |
| フォロワーは増えるがLINEが増えない | 導線が弱い | ストーリーズ・固定投稿・プロフィールの3箇所を見直す。特典の訴求を変える |
| LINEはあるが売れない | 関係構築か商品のズレ | 売る前の教育シーケンスを増やす。顧客5人に直接ヒアリング |
