# KPI

> 初期は売上より Audience Quality を見る。（構想 §12）

構想のこの方針は正しい。問題は「Audience Quality をどう測るか」が決まっていないこと。ここを実装する。

---

## 1. Audience Quality の測り方

Instagram のインサイトでは職業属性は分からない。**測れる場所は Newsletter の登録フォームだけ**。

登録フォームの職種（選択式・必須）を、そのまま集計する。

| 分類 | 職種 | カウント |
|---|---|---|
| **コア** | ジム/スタジオ 経営・運営 | ● |
| **コア** | ブランド/メーカー | ● |
| **コア** | マーケティング/PR/代理店 | ● |
| **コア** | 投資家/金融 | ● |
| **コア** | 施設開発/不動産 | ● |
| 準コア | トレーナー/インストラクター | ○ |
| 周辺 | 業界志望・学生 | — |
| 周辺 | その他（フィットネス好き） | — |

> **業界人比率 =（コア + 準コア）÷ 全購読者**

**目標：40%以上。** 30%を切ったらコンテンツがConsumer側に寄りすぎている。

### 補助的な質の指標

- 企業アカウントからのフォロー数（手で数える。月1回、フォロワーリストを目視）
- 企業からのプレスリリース・情報提供の件数（**最も正直な指標**。業界がこの媒体を認知した証拠）
- DMでの問い合わせの質（取材依頼、掲載依頼、協業相談）
- Threads での業界人からの返信

## 2. 週次で見る数字

毎週月曜（Newsletter配信後）、10分で埋める。

| KPI | 取得場所 | 合格ライン |
|---|---|---|
| **Newsletter 購読者数** | 配信ツール | 週+25以上 |
| **開封率** | 配信ツール | **40%以上** |
| クリック率 | 配信ツール | 8%以上 |
| **配信したか** | — | **Yes以外は許容しない** |
| Instagram リーチ | インサイト | 月次目標を按分 |
| 非フォロワー率 | インサイト | 70%以上 |
| 保存率（Carousel） | インサイト | 3%以上 |
| フォロワー増 | インサイト | 記録のみ |
| Threads 返信数 | Threads | 業界人からの返信を数える |
| プレスリリース受領 | メール | 月3件（10月）→ 月5件（12月） |

## 3. 月次関門

| 月末 | Newsletter | 業界人比率 | Instagram | Network | 売上 |
|---|---|---|---|---|---|
| 9/30 | 100 | 40% | 800 | — | ¥0 |
| 10/31 | 250 | 40% | 2,500 | PR受領 月3件 | ¥0 |
| 11/30 | 400 | 40% | 5,000 | 提案10社／JOBS 5件 | ¥0 |

**太字が本当の目標。** Instagram のフォロワー数だけが幅を持っているのは意図的で、
これは「当たり」の有無に依存する数字であり、意志で制御できないため（[business-plan-2026.md §01](business-plan-2026.md)）。

### 12月末の合格ライン（フォロワー数を含まない）

- [ ] 購読者 500人以上、うち業界人 250人以上

- [ ] 企業からのプレスリリース・情報提供が月5件以上
- [ ] PEOPLE インタビュー 5本以上
- [ ] 媒体資料が完成し、10社以上に提案済み

- [ ] JOBS 掲載企業 5社以上

## 4. 数字が悪いときの読み方

| 症状 | 原因 | 打ち手 |
|---|---|---|
| Instagram リーチが低い | Carousel偏重 | Reels の比率を上げる。Carouselでは新規リーチは取れない |
| フォロワーは増えるが Newsletter が増えない | 導線が弱い | プロフィール・Stories・Carousel最終ページの3箇所を見直す。登録特典（業界レポート等）を用意 |
| **業界人比率が30%未満** | Consumer側に寄りすぎ | BUSINESS / DATA の比率を上げる。TREND / BRAND を減らす |
| 開封率が30%台 | 件名か配信時間 | 件名に固有名詞と数字を入れる。「今週のニュース」ではなく「◯◯が△△を買収／ピラティス市場が◯%成長」 |
| プレスリリースが来ない | 業界に認知されていない | 受付窓口を明示。業界人50人にDM。PEOPLEインタビューを増やす |
| 提案しても売れない | 媒体資料に属性データがない | 購読者属性の集計を前面に。フォロワー数を売り文句にしない |

## 5. このKPI設計の考え方

**フォロワー数は記録するが、判断には使わない。**

構想 §15 の通り、10万人の一般消費者より1万人の業界人のほうが価値が高い。
であれば、追うべき数字は「フォロワー数」ではなく「**業界人の絶対数**」でなければ一貫しない。

> 業界人の絶対数 ＝ Newsletter購読者 × 業界人比率

12月末の目標 500 × 40% = **200〜250人**。
この200人が、Recruiting / Event / Consulting へ展開するときの起点になる。

**この数字だけは、何があっても落とさない。**
