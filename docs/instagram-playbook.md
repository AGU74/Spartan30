# Instagram 実行プレイブック — 0 → 15,000（18週間）

対象期間: 2026-09-01 〜 2026-12-31

---

## 1. 必要な数字を先に出す

フォロワーは「リーチ × フォロー転換率」でしか増えない。目標から逆算すると必要なリーチ量が確定する。

**フォロー転換率の目安**（新規フォロワー ÷ 非フォロワーリーチ）

| 水準 | 転換率 | 状態 |
|---|---|---|
| 悪い | 0.3%未満 | プロフィールか投稿の一貫性に問題 |
| 標準 | 0.8〜1.2% | 正常 |
| 良い | 2%以上 | 型が刺さっている |

**転換率1.2%で計算した必要リーチ**

| 月 | 目標増加 | 必要リーチ | 投稿数 | 1本あたり必要平均リーチ |
|---|---|---|---|---|
| 9月 | +800 | 67,000 | 44 | 1,500 |
| 10月 | +2,200 | 183,000 | 44 | 4,200 |
| 11月 | +4,500 | 375,000 | 44 | 8,500 |
| 12月 | +7,500 | 625,000 | 44 | 14,200 |
| 合計 | 15,000 | **1,250,000** | 176 | |

### この表の読み方 — ここが一番大事

**「平均14,200リーチ」を全部の投稿で出すのは不可能。** 実際の分布はこうなる。

- 全投稿の70%: 500〜3,000リーチ（大半はここ）
- 20%: 5,000〜20,000リーチ
- **8%: 50,000〜100,000リーチ**
- **2%: 200,000以上（＝当たり）**

12月に62.5万リーチを作るには、**10万リーチ級が3本**出ればほぼ足りる。
つまり戦略は「全投稿の質を上げる」ではなく、**「当たりが出る確率 × 打席数」を最大化する**こと。

- 打席数 = 週10本（これは意志の問題）
- 確率 = 当たった型の変奏を増やすこと（これはデータの問題）

**44本 ÷ 月で当たり2本＝確率4.5%。** これが目標ライン。9月のデータで型を特定できなければ、10月以降の数字は積み上がらない。

## 2. コンテンツの5つの型

すべての投稿はこの5つのどれかに属する。分類できない企画は作らない。

### 型A: 検証（伸びやすい／当たりが出る型）

数値が出る実験。「やってみた」ではなく「測ってみた」。

- 「筋トレ歴5年の男が1kmを全力で走ったらタイムはどうなるか」
- 「スレッドプッシュ50m、重量を10kg増やすと心拍はいくつ上がるか」
- 「ウォールボール100回を連続 vs 分割、どっちが速いか」

**ポイント:** 冒頭2秒に結果の一部を出す（「結論から言うと4分12秒でした」）。過程を見せてから結果、は最後まで見られない。

### 型B: 教育（保存されやすい／フォローに繋がる）

15〜30秒で1つの技術。1本1テーマを厳守。

- ローイングのドライブ、フォームの3ステップ
- バーピーブロードジャンプで消耗しない着地
- サンドバッグランジで腰が落ちる原因

**ポイント:** 「正しいやり方」より**「よくある失敗 → 修正」**の構成のほうが伸びる。自分の悪いフォームを先に見せる。

### 型C: 言語化（共感で拡散される）

視聴者が思っているが言葉にできていないことを代弁する。

- 「ベンチ100kg挙がるのに1km走れない人が見落としていること」
- 「レース中盤で必ず失速する人の共通点」
- 「フィットネスを1ヶ月でやめる人が最初の週にやっていること」

**ポイント:** この型は最も拡散する（シェアされる）が、最も外れも多い。全体の20%程度に留める。

### 型D: 現場・人物（信頼の蓄積）

レース会場、選手、自分の記録更新。フォロワーが「この人を見に来る」理由を作る。

**ポイント:** ※業務で得た素材・未公開情報は使わない（[business-plan-2026.md §3](business-plan-2026.md) の線引き参照）。

### 型E: ギア・レビュー（購買層を引き寄せる）

シューズ、グローブ、器具。将来のアフィリエイト／PR案件の土台にもなる。

### 配分

| 期間 | A検証 | B教育 | C言語化 | D現場 | E ギア |
|---|---|---|---|---|---|
| 9月（探索） | 25% | 25% | 20% | 20% | 10% |
| 10月以降 | **勝ち型を70%**、残り30%を他の型に配分 | | | | |

## 3. 冒頭2秒の設計

リールの成否の8割は最初の2秒で決まる。以下のどれかを必ず使う。

| 型 | 例 |
|---|---|
| 結論先出し | 「結論、これをやめたら1kmが20秒縮みました」 |
| 数値提示 | 「心拍185。ここから何ができるか試します」 |
| 否定・逆張り | 「毎日走るのは、この競技では逆効果です」 |
| 名指し | 「ベンチ100kg挙がるのに走れない人へ」 |
| 視覚的異常 | 説明なしで、いきなり異様な動きを見せる |

**やってはいけない冒頭:** 挨拶、自己紹介、「今日は〜について話します」。ここで50%が離脱する。

## 4. 週次オペレーション（週10〜25時間の配分）

| 曜日 | 作業 | 時間 |
|---|---|---|
| 月 | 先週データ分析（[kpi.md](kpi.md) を埋める）＋今週の企画確定 | 2h |
| 火 | 編集（3本） | 2h |
| 水 | 編集（3本）＋コメント・DM返信 | 2.5h |
| 木 | 撮影（次週分10本まとめ撮り） | 3h |
| 金 | 編集（4本） | 2.5h |
| 土 | 商品開発・コラボ調整 | 3h |
| 日 | 予備／ストーリーズ撮り溜め | 2h |
| 毎日 | ストーリーズ3枚、投稿後30分のコメント返信 | 0.5h×7 |
| | **合計** | **約20.5h** |

### 効率化の鉄則

1. **まとめ撮り。** 撮影日を分散させない。衣装を変えれば同日撮影とはバレない
2. **編集は1本15分以内。** それ以上かけても伸びは変わらない。凝るのは当たった型だけ
3. **投稿後30分のコメント返信は絶対にやる。** 初速のエンゲージメントがリーチを決める。ここだけは自動化も外注もしない
4. **11月から編集を外注。** 自分がやるのは企画・出演・コメント返信の3つだけにする

## 5. プロフィール設計（9/1までに完成）

| 要素 | ルール |
|---|---|
| 名前欄 | 「名前 \| ハイブリッドトレーニング」— **検索対象なのでキーワードを入れる** |
| 1行目 | 誰の何を解決するか。「走れない筋トレ勢を60分完走まで持っていく」 |
| 2行目 | 信頼の根拠（実績・経歴を1つだけ） |
| 3行目 | 個人の見解である旨 |
| 4行目 | CTA → LINE |
| ハイライト | 「はじめに」「30日プログラム」「実績」の3つだけ |

## 6. 成長施策の優先順位（費用対効果順）

1. **投稿本数を週10本維持する** — 他の全施策を合わせても、これに勝てない
2. **コメント・DMへの即返信** — 初速を作る。無料
3. **同規模アカウントとのコラボ** — 月3本。相手のフォロワーに直接届く。無料
4. **勝ち型の変奏** — 当たった投稿は、角度を変えて3回作り直す
5. **他アカウントのコメント欄での発言** — 大きいアカウントの投稿に価値あるコメントを残す。1日10件
6. ~~広告~~ — 型が確立するまで打たない
7. ~~フォロー返し狙い・相互フォロー~~ — **やらない。** エンゲージメント率が落ちてリーチが下がる。逆効果

## 7. 月末の判断ルール

各月末に必ずこの判定をする。感覚で続けない。

| 判定 | 条件 | アクション |
|---|---|---|
| **継続** | フォロー転換率 0.8%以上、保存率2%以上の投稿が月5本以上 | そのまま量産 |
| **型を変える** | 転換率0.8%未満だが、リーチは出ている | 投稿は届いているがフォローされていない → プロフィールとCTAを作り直す |
| **企画を変える** | リーチが全体的に1,000未満 | 型そのものが刺さっていない → 5つの型の配分を変え、別の型を主軸にする |
| **撤退判断** | 11月末時点でフォロワー3,000未満 かつ LINE 200人未満 | 15,000は諦め、コミュニティ／個別コーチングの少人数高単価に事業モデルを切り替える |

**最後の行が重要。** 撤退条件を先に決めておかないと、伸びない施策に18週間を使い切ることになる。
フォロワーが伸びなくても、500人のリストと10人の顧客がいれば事業は成立する。
